LogiStream

Oct 2026

Event-Driven Logistics & Real-Time Delivery Backend

  • Built an event-driven logistics backend in Python and FastAPI: order creation publishes events to Apache Kafka, and an independent dispatch service assigns the nearest driver using Redis GEO queries.
  • Implemented an idempotent consumer with a processed_events table written in the same PostgreSQL transaction as the business change, committing Kafka offsets manually only after the database commit.
  • Added retry with exponential backoff and a dead-letter topic for failed and malformed events, verified by injecting a bad message and reading it back from the DLQ.
  • Load-tested order creation (JWT auth, PostgreSQL write, Kafka publish per request) with 500 requests at 20 concurrent clients on a local Docker Compose setup: ~69 req/s, p95 latency 558 ms, 0 errors.
  • Containerized the full stack (API, PostgreSQL, Redis, Kafka, workers, Prometheus, Streamlit) with Docker Compose; built a live Streamlit + PyDeck dashboard and exposed request metrics at /metrics.
